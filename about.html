  • Created by Aaron Krawczyk
  • SNACBox - Child Safe Internet Gateway
  • Version 1.1.0
  • Web-Rated SNACBox (c) 2026

    • SNACBox is a personal project created to provide parents and guardians with an easy-to-use way to offer safe internet access. The idea was inspired by Aaron’s experience with cloud-based firewall systems, VLANs, and network access control systems. Business solutions offered features such as safe web search and video access, blocking known malicious IP addresses, and filtering internet access according to device-enrolment policies. Aaron wanted to bring these capabilities to a home network device that parents and guardians could manage.

    SNACBox—a Simple Network Access Box—can be added to most home networks to provide device-level internet access based on an age-rating system, following the KISS principle.
