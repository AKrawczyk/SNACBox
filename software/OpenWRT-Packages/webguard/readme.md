## Mannual Installation of WebGuard ##

Note: This is the test build of the luci-app-webguard APK package for OpenWRT 25.12+</br>
If you wish to install the WebGuard app mannualy the download the four webguard shell script files.

Run the scripts:

```bash
chmod +x webguard*.sh
webguard-install.sh
webguard-doc-firewall-config.sh
webguard-configure.sh
webguard-lan-DHCP-settings.sh
```

This will install all the comopnents and configureations needed on a clean install of OpenWRT
